# Development

Local setup guide for the Ritesh Prajapati cybersecurity portfolio.

## Prerequisites

- Node.js 18+ (LTS)
- npm 9+
- Supabase account + project

## Installation

```bash
git clone <your-repo-url>
cd <project-folder>
npm install
```

## Environment configuration

```bash
cp .env.example .env.local
```

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
NEXT_PUBLIC_SITE_URL=http://localhost:3000
NEXT_PUBLIC_PORTFOLIO_PROFILE_ID=your-profile-uuid

# Server-only
SUPABASE_SERVICE_ROLE_KEY=your-service-role-secret
```

## Supabase setup

1. Create project and note URL + keys.
2. (Optional) `supabase link --project-ref <ref>`
3. Apply migrations:

```bash
supabase db push
```

4. Enable email confirmation and disable open signup.
5. Configure OAuth providers if needed (callback: `<SITE_URL>/auth/callback`).

## Local development

```bash
npm run dev
```

Open http://localhost:3000.

## Authentication notes

- Login requires password + Google Authenticator TOTP.
- 3 failed attempts → 24-hour account lock (server-side).
- Dashboard at `/dashboard/*`.
- First-time setup: create account → enroll MFA → set profile photo
  (circular) → add projects, skills, blog posts, social links.
